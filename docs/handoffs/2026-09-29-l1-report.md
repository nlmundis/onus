### The review's findings, and what was done

- **F1 (major), fixed.** The no-rejection-region clause printed α/m as "at level α = <α/m>", so one sentence
  gave α two values; read with its own α, it said no outcome at this n could be met, when in a Holm family one
  can (clearer at 6 wins of 6 is met beside faster). It now reads "at level α/m = <level>", D2's words with
  the level named as D3 names it; the exact wording is vetoable. Test:
  `test_the_level_with_no_rejection_region_is_named_alpha_over_m`, which also requires every "α = " in the
  sentence to be the hypothesis's alpha.
- **F5, fixed.** `evaluate` read each used unit's outcomes three times (check, count, hash), so a mapping that
  answers differently when read again gave counts the hashed data does not. It now copies them once
  (`_outcomes_read_once`) and uses the copy throughout. Test: a two-faced mapping's evaluation equals that of
  one plain dataset or the other.
- **F7, fixed in part.** `record_read` kept a relative `reads_path` as spelled, so after a change of directory
  `render` refused the very file. It now resolves the path when it records, and `receipt_from_line` does the
  same, so the two receipts of one read stay equal. The case-spelling half is open (below).
- **T1 (major), fixed.** The lock test showed only that the append waits for the lock. A new test lets a
  second writer's read land while `record_read` waits for the lock and requires the seal to refuse on it. It
  waits on a watched `fcntl.flock` call, not a sleep, so moving the flock after the seal fails it every time.
- **T2 to T7, fixed.** New tests: a read equal to the first read but not to a later re-read is sealed (T2); a
  count horizon's read with a datetime or string `as_of` is refused (T3); the malformed-line test edits
  `supersedes` and `reason` with their partner well formed (T4) and adds `n = 0` and prereg hashes of 11 and
  13 hex digits (T7); `test_render_reads_no_clock` now watches, through `sys.setprofile`, every call into
  datetime's and date's `now`, `utcnow`, and `today` and the time module's clock functions, with a control
  showing it sees each kind (T5); and "no MDE exists" at exactly 80% power, one trial at p0 = 4/5 and alpha
  0.8, is tested (T6), where `>` raised.
- **T8, fixed.** The six rules the tests killed but no curated mutant named now have mutants.
- `mutt_check.toml` gains 18 mutants, one per rule above, 249 in all. Each was applied alone in a scratch copy
  and seen failing its named test for its named reason. `a_tampered_rule_evaluated`'s anchor moved with
  `evaluate`'s first lines. A test also covers outcomes that are not a mapping, a branch F5's split exposed.

## Open

- **Questions from the review, for the maintainer (the spec does not decide them):**
  - F3: `assert_quoted` passes a document that holds the exact sentence and, elsewhere, a copy with other
    figures; the plan says it "fails a test when a document quotes a figure that is not the rendered
    sentence". What marks a span as a quote of the sentence, so a stale copy can be found: its hypothesis name
    and prereg id on one line, a delimiter documents wrap quotes in, or the plan's wording narrowed to "the
    document holds the sentence"? The docstring now states the gap.
  - F6: at n = 4000, the MDE's four fixed decimals print 1.0000 at p0 = 999/1000 (the MDE is 0.99994) and
    overstate the effect beyond p0 by about 24% at p0 = 1/1000000. How many digits should it carry: fixed
    places as built, significant digits of its distance from p0, or enough to separate it from p0 and from 0
    and 1? The choice pins sentences once released.
  - F7, case half: on a case-insensitive disk "Reads.jsonl" is refused for "reads.jsonl", since `resolve()`
    does not fold case. Keep D1's "equal once resolved", or compare by file identity (`os.path.samefile`),
    which would also accept a hard link?
- **Choices the spec did not make (vetoable):**
  - Numbers: p-values are printed to four significant digits, rounded half to even from the exact fraction;
    alphas and p0 are printed exactly (a finite decimal, else "a/b"); the MDE is printed to four decimal
    places, rounded away from the null so the printed effect still reaches the power (F6 above). These pin
    sentences once released.
  - An early read still carries the MDE clause when it is not met.
  - After one re-read, every later read of that experiment needs `supersedes`, because it differs from at least
    one earlier read (now tested, T2).
  - `render` does not compare `as_of` with the line. It refuses when any line of the reads file is malformed.
  - `read/2` labels are "met" or "not met" only, so the post hoc label (L1 step 4) needs a schema change.
- **Known limits:**
  - `fcntl` is POSIX-only, so importing `onus.prereg` fails on Windows. Say so, or import it lazily.
  - A read refused because `supersedes` was given with no earlier read leaves an empty reads file behind.
  - The seal binds only the reads file it is given (D6).
- **Plan text:** "prereg and report" still describes `record_read(..., now=None)` as built; that describes the
  merged state before this change and belongs to a plan amendment or edit, not to this branch.
